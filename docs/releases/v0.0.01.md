# VueTorrent Next Mod v0.0.01

首个公开预览版本，基于 VueTorrent 提供完整的 qBittorrent 网页管理能力，并完成以 Transmission Next UI 为主要参考的界面重构。

## 主要变化

- 重构桌面端侧栏、顶部工具栏和仪表盘布局。
- 新增下载、上传、活跃任务和磁盘空间统计卡片。
- 引入接近 shadcn/ui 的主题变量、圆角、边框和交互风格。
- 默认使用表格视图，并优化列表与表格的信息密度。
- 重构登录页、任务卡片、筛选器和设置页面样式。
- 新增重构界面的简体中文导航与仪表盘翻译。
- 修复深色主题下设置标签栏显示为白色的问题。

## 安装

下载 `vuetorrent.zip` 并解压，将 qBittorrent 的替代网页用户界面目录指向包含 `index.html` 的解压目录。

## 验证

- 类型检查通过。
- 自动化测试通过。
- 生产构建通过。

这是预览版本，建议在升级或替换现有网页界面前备份配置。
